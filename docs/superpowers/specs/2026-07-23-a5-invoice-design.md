# Official A5 Rent Invoice Customization Design Spec

**Date**: 2026-07-23  
**Target System**: Pakdee Apartment / SmartApart System  
**Feature**: Official A5 Form Printed Invoice System (ตามแบบฟอร์มจริง + ระบบกระจายรายการลงหมายเหตุ)  

---

## 1. Summary of Form Structure & Requirements

1. 📄 **ขนาดกระดาษและการจัดหน้า**: A5 แนวนอน/แนวตั้ง พอดีกระดาษ พร้อมแถบคาดหัวบิลสีดำ `ใบแจ้งหนี้` และกรอบชื่อหอพักมุมขวา
2. 🏠 **จัดรูปแบบที่อยู่**: `ที่อยู่ : ห้อง [เลขห้อง] [ที่อยู่อพาร์ทเมนท์ส่วนที่เหลือ]`
3. 📅 **ประจำเดือน**: แสดงเฉพาะชื่อเดือนภาษาไทย (เช่น `ประจำเดือน : กรกฎาคม`)
4. 📘 **เล่มที่ และ เลขที่**:
   * **เล่มที่** = เลขห้องพัก (เช่น `A3`) (ระบบเติมให้อัตโนมัติ + ปรับแก้เองได้)
   * **เลขที่** = งวดเดือนที่เข้าพัก (ระบบนับงวดให้อัตโนมัติ + ปรับแก้เองได้)
5. 💡 **ระบบจัดการ "ค่าใช้จ่ายอื่นๆ" และ "หมายเหตุ" (Smart Other Expenses & Notes Mapping)**:
   * ในฟอร์มออกบิล เจ้าของหอพักสามารถ **เพิ่มรายการย่อยค่าใช้จ่ายอื่นๆ** ได้หลายรายการ เช่น:
     * *ค่าทำความสะอาด*: 300 บาท
     * *ค่าซ่อมทีวีเสียหาย*: 500 บาท
   * **การรวมเงินลงตาราง A5**: ระบบจะนำยอดเงินย่อยทั้งหมด (300 + 500 = 800 บาท) ไปรวมใส่ในแถว **`ค่าใช้จ่ายอื่นๆ`** ของตารางให้อัตโนมัติ
   * **การสร้างหมายเหตุอัตโนมัติ**: ระบบจะนำชื่อรายการย่อยทั้งหมดมาพิมพ์เรียงในแถบ **`*** หมายเหตุ`** ท้ายบิลให้อัตโนมัติ เช่น:  
     `*** หมายเหตุ : ค่าทำความสะอาด (300 บ.), ค่าซ่อมทีวีเสียหาย (500 บ.)`

## 3. Data Schema & Model Extensions

Extend `Invoice` model:
- `bookNo`: String? (Default: เลขห้อง e.g. "A3")
- `invoiceNoStr`: String? (Default: งวดเดือนเข้าพัก e.g. "1")
- `otherFeeDetails`: String? (JSON String เก็บรายการย่อย `[{ name: "ค่าทำความสะอาด", amount: 300 }, { name: "ค่าซ่อมทีวี", amount: 500 }]`)
- `otherNote`: String? (ข้อความหมายเหตุรวมที่สร้างให้อัตโนมัติ หรือพิมพ์แก้เอง)

---

## 4. User Workflow during Invoice Creation

1. เมื่อกดออกบิล/สร้างใบแจ้งหนี้ประจำเดือน:
   * ค่าน้ำ ไฟ ค่าห้อง ดึงตามมิเตอร์และราคาห้องให้อัตโนมัติ
   * มีปุ่ม `[ + เพิ่มค่าใช้จ่ายอื่นๆ ]` สามารถใส่ชื่อรายการ + ระบุจำนวนเงินกี่บาทก็ได้
2. ระบบคำนวณและจัดลงฟอร์ม A5 ให้อัตโนมัติ
3. แสดงปุ่ม `[ 🖨️ พิมพ์ใบแจ้งหนี้ A5 ]` และ `[ 🖨️ พิมพ์บิล A5 ทั้งตึก ]`
