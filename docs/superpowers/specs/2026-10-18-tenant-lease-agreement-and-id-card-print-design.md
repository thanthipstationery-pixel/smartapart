# Tenant Lease Agreement & ID Card Print System Design Spec

**Date**: 2026-10-18  
**Target System**: SmartApart Management System  
**Feature**: Official A4 Tenant Lease Agreement, Asset Rental Contract, Apartment Rules, and Tenant ID Card Attachment Print System (ระบบจัดทำและพิมพ์สัญญาเช่าห้องพัก สัญญาเช่าทรัพย์สิน กฎระเบียบ และใบแนบสำเนาบัตรประชาชน ขนาด A4)

---

## 1. Executive Summary & User Requirements

1. **Auto-populated Lease Agreements from Tenant Registration (Check-in)**:
   - ดึงข้อมูลจากการลงทะเบียนผู้เช่าใหม่มาหยอดลงในสัญญาอัตโนมัติ 100%
   - ข้อมูลคู่สัญญา: ชื่อ-สกุล, เลขประจำตัวประชาชน 13 หลัก, ที่อยู่ตามบัตร, เบอร์โทร, อายุ, ชื่อเล่น, บุคคลติดต่อฉุกเฉิน/ความสัมพันธ์/เบอร์โทร, ที่ทำงาน/สถานศึกษา
   - ข้อมูลห้องพักและอาคาร: เลขห้องพัก, ชื่ออาคาร/อพาร์ทเมนท์ (เช่น ธารทิพย์อพาร์ทเมนท์, วิชุดาอพาร์ทเมนท์, พักดีอพาร์ทเมนท์), ที่อยู่อาคาร, เบอร์โทรติดต่อ
   - ข้อมูลการเงิน: เงินประกันสัญญาเช่า (๓.๑), ค่าเช่าห้องพักเดือนแรก (๓.๒), ยอดรวมเงินที่ชำระในวันทำสัญญา

2. **Dual-Contract Structure Issued as a Pair (สัญญาคู่แฝด)**:
   - **สัญญาเช่าห้องพัก** (หน้า ๑ - ๓): ข้อตกลง ๑๓ ข้อ, เงินประกัน, การบอกเลิก ๓๐ วัน, ค่ารักษามิเตอร์, ค่าทำความสะอาด ๓๐๐ บาท เมื่อย้ายออก, ลายมือชื่อคู่สัญญา
   - **สัญญาเช่าทรัพย์สิน** (หน้า ๔ - ๕): เช่าเฟอร์นิเจอร์และเครื่องใช้ไฟฟ้า (โทรทัศน์, ตู้เย็น, ตู้เสื้อผ้า, เตียงนอน, ฟูก ฯลฯ)
     - ระบุยอดในเนื้อหาหน้า ๔: *"ซึ่ง ผู้ให้เช่า ได้นำทรัพย์สินมาให้ผู้เช่า เช่าไว้ `[ค่าห้องรวม]` บาท"*
     - ข้อ ๒.๑ อัตราค่าเช่าห้องพัก: `๑,๐๐๐` บาท (Default)
     - ข้อ ๒.๒ อัตราค่าเช่าทรัพย์สินภายในห้องพัก: `[ ค่าห้องรวม - ๑,๐๐๐ ]` บาท
     - รวมค่าเช่าห้องต่อรายเดือน: `[ ค่าห้องรวม ]` บาท
     - ข้อตกลง ๗ ข้อ และลายมือชื่อคู่สัญญา

3. **Apartment Rules Document (กฎระเบียบสำหรับผู้พักอาศัยในอพาร์ทเมนท์)** (หน้า ๖):
   - กฎระเบียบมาตรฐาน ๑๘ ข้อ (กำหนดเวลาขนย้าย ๐๘:๐๐ - ๑๘:๐๐ น., ค่าปรับล่าช้า, การทิ้งขยะ, ข้อห้ามทำอาหาร, ห้ามสูบบุหรี่, ค่าปรับกดสัญญาณเตือนภัย ๑,๐๐๐ บ. ฯลฯ)

4. **Tenant ID Card Attachment with Security Watermark (ใบแนบสำเนาบัตรประชาชน)** (หน้า ๗):
   - จัดวางรูปถ่ายบัตรประชาชนของผู้เช่า ๑ (และผู้เช่า ๒ ถ้ามี) ลงบนแผ่น A4
   - **ระบบความปลอดภัย PDPA (Watermark Burn-in)**: ประทับลายน้ำตัวอักษรจางๆ คาดกลางรูปตั้งแต่ฝั่งหน้าบ้าน: *"ใช้สำหรับทำสัญญาเช่าห้องพัก [ชื่ออพาร์ทเมนท์] เท่านั้น"*
   - มีเส้นลงลายมือชื่อ *"รับรองสำเนาถูกต้อง"* สำหรับให้ผู้เช่าลงนาม

5. **Second Tenant (Co-tenant) Support**:
   - เพิ่มตัวเลือกในหน้าลงทะเบียนสำหรับ "ผู้เช่าคนที่ ๒ (ผู้ร่วมพักอาศัย)" แบบพับเก็บได้ (Collapsible Accordion) พร้อมระบบ AI สแกนบัตรประชาชน

6. **Flexible Contract Duration**:
   - ระยะเวลาสัญญาเริ่มต้น ๖ เดือน พร้อมตัวเลือกลัด (๑ เดือน, ๓ เดือน, ๖ เดือน, ๑๒ เดือน หรือระบุเอง) และระบบคำนวณวันสิ้นสุดสัญญา (`endDate`) ให้อัตโนมัติ

## 3. Database Schema Changes (`prisma/schema.prisma`)

ขยายโมเดล `Tenant` ในฐานข้อมูลเพื่อเก็บรูปบัตรประชาชนและข้อมูลสัญญาเพิ่มเติม:

```prisma
model Tenant {
  // --- Existing fields ---
  id                   String     @id @default(uuid())
  name                 String
  phone                String
  idCard               String?
  address              String?
  email                String?
  lineId               String?
  workplace            String?
  emergencyName        String?
  emergencyRel         String?
  emergencyPhone       String?
  securityDeposit      Float      @default(0)
  keycardCount         Int        @default(0)
  keycardDeposit       Float      @default(0)
  keycardCode          String?
  note                 String?
  startDate            DateTime   @default(now())
  endDate              DateTime?
  status               String     @default("ACTIVE")
  checkedOutAt         DateTime?
  noticeDate           DateTime?
  expectedCheckOutDate DateTime?
  keycardReturnedCount Int        @default(0)
  keycardRefundedAt    DateTime?
  keycardRefundAmount  Float      @default(0)
  roomId               String
  room                 Room       @relation(fields: [roomId], references: [id], onDelete: Cascade)
  invoices             Invoice[]

  // --- NEW FIELDS FOR LEASE AGREEMENT & SECOND TENANT ---
  nickname             String?    // ชื่อเล่นผู้เช่า ๑
  age                  Int?       // อายุผู้เช่า ๑
  idCardImage          String?    // Base64 Data URL รูปบัตรประชาชนผู้เช่า ๑ (ฝังลายน้ำแล้ว)
  
  // ผู้เช่าคนที่ ๒ (Co-tenant)
  secondTenantName           String?
  secondTenantNickname       String?
  secondTenantAge            Int?
  secondTenantIdCard         String?
  secondTenantAddress        String?
  secondTenantPhone          String?
  secondTenantWorkplace      String?
  secondTenantEmergencyName  String?
  secondTenantEmergencyRel   String?
  secondTenantEmergencyPhone String?
  secondTenantIdCardImage    String? // Base64 Data URL รูปบัตรประชาชนผู้เช่า ๒

  // ข้อมูลสัญญาเช่า
  contractNumber             String? // เลขที่สัญญา เช่น 101/2569
  contractDurationMonths     Int     @default(6) // ระยะเวลาสัญญา (เดือน) เช่น 1, 3, 6, 12
  roomRentShare              Float   @default(1000) // สัดส่วนค่าเช่าห้องพัก (บาท)
  assetRentShare             Float?  // สัดส่วนค่าเช่าทรัพย์สิน (บาท) (คำนวณอัตโนมัติ = ค่าห้องรวม - roomRentShare)

  @@index([roomId, status])
}
```

## 4. UI/UX Workflow & Components

### 4.1 CheckInModal & EditTenantModal Enhancements
1. **รูปบัตรประชาชน (Client-side Compression & Watermarking)**:
   - เมื่อเลือกรูปบัตรประชาชน:
     - ปรับขนาดและบีบอัดภาพให้อัตโนมัติ (JPEG ~100-200 KB)
     - ฝังลายน้ำจางๆ กลางภาพด้วย Canvas ทันที: `"ใช้สำหรับทำสัญญาเช่าห้องพัก [ชื่อตึก] เท่านั้น"`
     - แสดงการ์ดพรีวิวรูปบัตร พร้อมปุ่ม `เปลี่ยนรูป` และ `ลบรูป`
2. **Co-Tenant Collapsible Accordion**:
   - ปุ่มสลับ: `[ + เพิ่มผู้เช่าคนที่ ๒ (ผู้ร่วมพักอาศัย) ]` (Default พับปิด)
   - เมื่อเปิด: มีปุ่มสแกนบัตรประชาชน AI ของผู้เช่าคนที่ ๒ และช่องกรอกข้อมูลแยกส่วน
3. **Rental Contract Configuration Box**:
   - ปุ่มเลือกระยะเวลา: `[ 1 ด. ]` `[ 3 ด. ]` `[ ⭐ 6 ด. ]` `[ 12 ด. ]` `[ กำหนดเอง ]`
   - วันที่สิ้นสุดสัญญา: ระบบคำนวณและแสดงผลให้อัตโนมัติ
   - เลขที่สัญญา: แนะนำค่าเริ่มต้น `[เลขห้อง]/[ปี พ.ศ.]` และพิมพ์แก้ไขได้
   - ยอดแบ่งค่าเช่า: แสดงค่าห้องพัก 1,000 บาท และค่าเช่าทรัพย์สินอัตโนมัติ
4. **Action Shortcut**:
   - เมื่อลงทะเบียนสำเร็จ มีปุ่ม **"📄 พิมพ์สัญญาเช่าทันที"**

### 4.2 LeaseAgreementModal (New Component)
สร้างคอมโพเนนต์ใหม่ `src/components/modals/LeaseAgreementModal.tsx`:
* **Header & Toolbar**:
  * ตัวเลือก Checkbox:
    * `[✓] พิมพ์ทั้งหมด (๗ หน้า)`
    * `[✓] สัญญาเช่าห้องพัก (หน้า ๑-๓)`
    * `[✓] สัญญาเช่าทรัพย์สิน (หน้า ๔-๕)`
    * `[✓] กฎระเบียบ (หน้า ๖)`
    * `[✓] สำเนาบัตรประชาชน (หน้า ๗)`
  * ปุ่ม **"🖨️ สั่งพิมพ์เอกสาร (A4 / บันทึก PDF)"**
  * ปุ่ม **"✕ ปิด"**
* **A4 Print Engine**:
  * ใช้ CSS `@media print` ร่วมกับ `@page { size: A4 portrait; margin: 15mm 20mm; }`
  * การตัดหน้ากระดาษแบบเป๊ะ: `.a4-page { page-break-after: always; break-after: page; min-height: 297mm; }`
  * รองรับการเปิดหน้าต่างพิมพ์ของเบราว์เซอร์ (`window.open` หรือ `window.print`) ที่สามารถเลือก Save as PDF ได้อย่างสมบูรณ์แบบ

## 5. Security & PDPA Protection

1. **Client-side Watermark Burn-in**:
   - ลายน้ำถูกเรนเดอร์ลงในพิกเซลของภาพก่อนส่งขึ้นเซิร์ฟเวอร์
   - แม้ไฟล์ภาพจะถูกดาวน์โหลดหรือคัดลอก ลายน้ำก็จะไม่สามารถลบออกได้ ป้องกันการนำไปใช้แอบอ้างทำธุรกรรมอื่น
2. **Access Control**:
   - การเข้าถึงรูปบัตรประชาชนและข้อมูลสัญญาจำกัดเฉพาะผู้ดูแลระบบที่ผ่านการพิสูจน์ตัวตนแล้ว (Authenticated Admin Session)
3. **No Direct Public URLs**:
   - ไม่มีการเปิด Public Storage Bucket สู่ภายนอก

## 6. Implementation Stages & Next Steps

1. **Phase 1**: อัปเดต `prisma/schema.prisma` และรัน `prisma generate` / migration
2. **Phase 2**: ปรับปรุง API `/api/tenants` และ `/api/tenants/[id]` ให้รองรับฟิลด์ใหม่ทั้งหมด
3. **Phase 3**: อัปเดต `CheckInModal.tsx` และ `EditTenantModal.tsx` ให้มีพรีวิวรูปบัตรประชาชน, ลายน้ำ, ส่วนผู้เช่าคนที่ ๒ และตัวเลือกสัญญา
4. **Phase 4**: พัฒนา `LeaseAgreementModal.tsx` ครบทั้ง ๗ หน้าตามต้นฉบับเป๊ะ พร้อมระบบเลือกหน้าพิมพ์และ Print Engine
5. **Phase 5**: เชื่อมต่อปุ่ม "พิมพ์สัญญาเช่า" ในหน้าแดชบอร์ด, หน้ารายละเอียดห้องพัก และแท็บผู้เช่า
6. **Phase 6**: ตรวจสอบและทดสอบระบบพิมพ์ (A4 Print / Save as PDF) บนอุปกรณ์ต่างๆ
